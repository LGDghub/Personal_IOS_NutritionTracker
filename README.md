# Nutrition OS

Personal iPhone PWA for meals, macros, hydration, supplements and weight tracking.

This repository continues the existing Nutrition OS PWA package. It uses local device storage and JSON backups. Live ChatGPT sync is not connected yet.

## GitHub Pages

In **Settings → Pages**, choose **Deploy from a branch → main → /(root)** and Save.

After deployment, open the URL shown by GitHub in Safari and choose **Share → Add to Home Screen**.

See [README.txt](README.txt) for usage and deployment details, [RELEASE-NOTES.md](RELEASE-NOTES.md) for verification and [LIVE-SYNC.md](LIVE-SYNC.md) for the pending authenticated sync design.

Keep personal JSON backups out of this public repository.
